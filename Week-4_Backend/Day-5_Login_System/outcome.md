**Expected Outcome**

The system should allow a user to register using name and email, then log in using the same credentials.
If the login credentials are correct, the user should be redirected to a success page displaying the user’s details.
If the credentials are incorrect, an alert message should be shown once.

**Actual Outcome**

The user registration and login functionality worked correctly.
Valid users were able to log in and view the success page with their information.
When invalid credentials were entered, an alert message was displayed.
